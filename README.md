# **Krutoy Toose**

Interactive Telegram Mini App clicker game built with **TypeScript** and **Telegram WebApp API**.

# **🚀 Features**

* **Telegram Native Integration**: Uses Telegram `initData` authentication, native theme colors, and Safe Area adaptation.  
* **Clicker Game Mechanics**: Real-time coin generation, score tracking, and account progress.  
* **REST API Connection**: Connects to backend services for saving game state and player profiles.

# **🛠️ Tech Stack**

* **Frontend**: TypeScript, HTML5, SCSS  
* **Platform**: Telegram Mini Apps WebApp API  
* **Backend Integration**: REST API

# **🔧 Local Development**

1. Clone the repository:  
   `git clone https://github.com/TimurKhen/krutoy-toose.git`  
   `cd krutoy-toose`  
2. Install dependencies:  
   `npm install`  
3. Run local server:  
   `npm start`


# Docker:

Build: `docker build -t krutoi-toose .`
<br>
Run: `docker run -d -p 8080:80 krutoi-toose:latest`

check: http://localhost:8080/
